→
SCRATCH · 方塊

Your mission · 完成 BMI 計算器

Open Scratch and build the whole program yourself. · 打開 Scratch，依你的流程圖自行完成整支程式。

  1. Start with the green flag. · 用「當綠旗被點擊」開始。
  2. Ask for weight (kg) and height (m), then store both answers. · 詢問並儲存體重、身高。
  3. Calculate and store BMI = weight ÷ (height × height). · 算出 BMI。
  4. Use if / else to output Underweight, Normal, Overweight, or Obesity. · 判斷並顯示四種分類。
  5. Test different numbers, especially BMI 18.5, 24, and 27. · 測試三個分界值。
